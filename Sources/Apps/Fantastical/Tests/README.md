# Fantastical: checking by hand

Fantastical 4 in English, with a calendar that has some events. Use a test calendar for the steps that add or delete.

## Month view (Command 3), and the quarter view (Command 4)

1. Right arrow: the next day, with its number of events. Left arrow: the day before. A day with no events is said too.
2. Option Down arrow: the same weekday a week later. Option Up arrow: a week earlier.
3. Keep going Right past the last week shown: the view turns and the next day is said, none skipped or said twice, and no other date is said over it.
4. Command T: today. Then Option Up arrow: the same weekday last week, not another month.
5. Down arrow on a day with events: its first event, without the day's date, and "1 of" the number. Down again: the next. Up from the first: the day again.
6. In the search field, the arrows move in the text as usual.

## Week view (Command 2) and day view (Command 1)

7. Straight after the Command key, without Tab: Left and Right arrow go a day at a time; Down and Up through the day's events, the all-day ones first.
8. Option Down arrow in the week view: the same weekday next week.

## An event's details

9. Return on an event: its details open on the title, with the keyboard in it. Tab: the next control, round to the first after the last. The four date and time controls come as start date, start time, end date, end time, and the time controls say a time only.
10. Return or Space on a pop-up button or a checkbox there: it is pressed.
11. Escape: the details close and the event is said again, once, with nothing said over it.
11a. In the month view, on a day with more events than its box shows (seven, say): Return on each of them, the last too, opens that event's details; Escape comes back to it. The view stays the month view.
11b. Command Tab to another app and back, then Return on an event without pressing anything else first: its details open as in 9, and Escape closes them.
11c. In the day view (Command 1): Return on an event puts the keyboard in the title of the details beside the day; Tab goes through them; Escape comes back to the event.
11d. In the quarter view (Command 4) with weeks too small to show any event's title: Return on an event says "Could not open this event" after about two seconds, and the arrows go on working.
11e. Return twice in quick succession, and Return followed at once by Down arrow: nothing is said twice, and "Could not open this event" is not said for an event that opened.
12. Delete on an event: Fantastical asks about that event, and no other. The same on an event beyond the ones the day's box shows. Delete on a day with no event chosen: nothing is deleted, and TurnOver says so.

## A new event (Command N)

13. Type "Lunch tomorrow 1pm": Option Return says what Fantastical has understood, and nothing is added.
14. Type " with " and the start of a contact's name: after a moment the first suggestion and how many there are. Down and Up arrow: each suggestion and its place. Return on one: the sentence as it now stands. The same after " at " and after a slash.
15. Return with no suggestion chosen: "Added", and the event in a line. Command Return from another field of the popover: the same.

## Go to Date (Shift Command T)

16. The dialog opens on the date field, said with its weekday. Tab or Right arrow: "month" and the month, then "year" and the year; Shift Tab or Left arrow: back. Tab from the year: the Cancel button. Shift Tab from Cancel: the year. Up or Down arrow: the part's new value, then the whole date, once ("15, Sunday, 15. November 2026").
